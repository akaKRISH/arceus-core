# Phase 0 Prompt — Inspect the Environment (NO CHANGES)

Work in the current `arceus-core` folder. **Inspection only. Do not edit files, install dependencies, download model weights, initialize/reset Git, run migrations, or create a remote repository.**

Report:
1. Current working directory and list of project files/folders.
2. Operating system and version.
3. Python versions (`py -0p` and `py -3.12 --version` on Windows, or equivalent), Git version, and status/branch/remote if a repository already exists.
4. RAM, available disk space, GPU model/VRAM/driver if detectable (`nvidia-smi` on supported NVIDIA systems).
5. Node/Rust availability, but label them optional for Phase 1.
6. Any existing virtual environments, databases, or uncommitted changes.
7. Minimum blockers for the Python + SQLite MVP.

Do not include secrets, usernames unnecessarily, full personal file listings, or unrelated private paths in the report. Do not claim unavailable hardware is present. End with a short recommendation; wait for a separate implementation prompt.
